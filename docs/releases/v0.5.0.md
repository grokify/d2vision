# v0.5.0

**Release Date:** 2026-11-01

Takes up three loose ends from v0.4.0: Mermaid output is now on the command
line, `generate` handles IDs that D2 reserves, and the documentation pages that
moved in v0.4.0 redirect from their old addresses.

## Highlights

- `generate --to mermaid` writes the spec as a Mermaid flowchart
- `generate` quotes IDs that D2 reserves, such as `label`, `shape`, `style`, and `left`
- The pages that moved in v0.4.0 redirect from their old addresses, keeping any anchor

## Features

### Mermaid on the command line

v0.4.0 added a Mermaid writer to the Go library. The command now exposes it:

```bash
d2vision generate spec.toon --to mermaid > diagram.mmd
```

The default is still D2. Containers become subgraphs, a node is named by its
whole path, and classes become `classDef`s. Mermaid has no grid, so `gridColumns`
and `gridRows` are ignored, and a spec with sequences or tables is refused with
an error. `--to` accepts `d2` and `mermaid`, and anything else is an error.

### Reserved words as IDs

D2 reads words such as `label`, `shape`, `style`, `left`, `top`, `width`, and
`class` as settings. A node or container whose ID was one of them produced D2
that `d2` refused with `reserved keywords are prohibited in edges`. These IDs are
now written in quotes, so the diagram compiles and shows the node you named.
The check uses D2's own list of reserved words, and a test fails if D2 adds one
that `generate` does not know.

Three words stay special even when quoted: `layers`, `scenarios`, and `steps`.
D2 uses them to define the boards of a multi-board diagram. A plain node can
have one of these names, but a container that has one cannot have edges to or
from the nodes inside it. Give such a container another ID. The
[troubleshooting guide](../guides/troubleshooting.md) has the error message and
the fix.

### Redirects for the moved pages

v0.4.0 moved the guides, commands, cookbook, examples, API reference, lint
rules, and troubleshooting pages under `guides/`, and the case study under
`design/case-studies/`. Each of the 34 old addresses now redirects to the new
page and keeps any `#anchor`, so a link such as `/commands/lint/` or
`/lint-rules/#corner-near` still lands where it should.

### Documentation

- The [generate page](../guides/commands/generate.md) covers `--to mermaid` and reserved words, and no longer says the input format is detected from the file name. The default is TOON, and JSON and YAML are named with `-f`.
- The README, [getting started](../guides/getting-started.md), and the [commands index](../guides/commands/index.md) mention the Mermaid output.
- The [API reference](../guides/api-reference.md) notes the quoting of reserved words.
- The [troubleshooting guide](../guides/troubleshooting.md) has an entry for each of the two errors D2 gives for reserved words.

### Build

- The documentation site is built from `requirements.txt`, which now includes `mkdocs-redirects`. Install with `pip install -r requirements.txt` before `mkdocs build`.

## Upgrading

v0.5.0 is backward compatible with v0.4.0. The one change in output is that an ID
D2 reserves is now written in quotes. A diagram that compiled before is unchanged,
and one that did not compile now does.

The documentation tooling gains a dependency: building the site needs
`mkdocs-redirects`, installed from `requirements.txt`. The command line and the
Go library gain no new dependencies.
