# v0.2.0

**Release Date:** 2026-09-12

Adds a deterministic static linter for D2, a diagram quality review command,
label compaction, layout-engine selection, and expanded documentation.

## Highlights

- Static D2 linter with a stable rule-code registry, YAML config, and `--list` / `--explain`
- New `review` command scoring layout, whitespace, legend, and hierarchy
- New `compact` command that shortens long node labels behind a legend
- Layout-engine-selectable rendering (Dagre / ELK) plus a font-size floor

## Features

### Lint

- **`corner-near`** (error): a compiler-based check flagging elements pinned to a
  corner via `near`, which wastes ~50% of the canvas; recommends an edge-center
  `near`.
- **`text-overlap`** (warning, opt-in): a post-layout, engine-dependent check for
  connection labels whose rendered rectangles overlap another label or an
  unrelated node.
- **Rule registry** with stable `Code` identifiers and human-facing
  title/severity/suggestion/remediation, surfaced via `lint --list` and
  `lint --explain <code>` (modeled on `net/http` status constants).
- **YAML config** (`.d2vision.yaml`, golangci-style): enable/disable rules,
  override severities, and pass per-rule settings; one invocation runs the whole
  policy.

### Commands

- **`review`**: comprehensive diagram quality review (layout, whitespace, legend,
  hierarchy) for D2 or SVG input, with agent specs/skills backing AI-assisted use.
- **`compact`**: render a diagram with long node labels replaced by short numeric
  keys plus a legend mapping.

### Rendering

- **`CompileWithLayout`**: lay out with a named engine (`dagre` or `elk`) and
  return the laid-out diagram for post-layout analysis.
- **Font-size floor**: apply a minimum font size to every label before compiling.

### Documentation

- **Lint Rules** reference (`docs/lint-rules.md`) with codes, severities, and
  remediation.
- **Layout Engines** guide (`docs/cookbook/layout-engines.md`) comparing Dagre,
  ELK, and TALA (what D2 ships) with the force-directed engines (ForceAtlas2,
  SFDP, CoSE) and when each is appropriate.
- Command pages for `review`, `compact`, and expanded `lint`.

## Upgrading

v0.2.0 is backward compatible with v0.1.0. All additions are new commands, a new
`lint` package, and new `render` entry points; existing APIs and command behavior
are unchanged.
