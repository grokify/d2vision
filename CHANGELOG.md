## [v0.3.0] - 2026-09-28

### Highlights

- New `card` command renders datasheet-style infographic cards from JSON to an animated SVG, PNG, or looping GIF
- Step-sequenced flows: number the steps and timing, loop length and step badges are derived
- Panels derived from PIDL protocol files, so a diagram cannot drift from its protocol
- New `svg2gif` command converts any animated SVG (SMIL or CSS, including D2 animated edges) to a looping GIF

### Added

- `card` package: render datasheet-style infographic cards from a JSON definition to a deterministic SVG with stable ids ([`884193e`](https://github.com/grokify/d2vision/commit/884193e))
- Animated flow dots on edges with `forward`, `reverse`, `alternate` and `both` modes, driven by SMIL ([`884193e`](https://github.com/grokify/d2vision/commit/884193e))
- Step scheduler: ordered steps with derived timing and loop length, plus numbered step badges on edges ([`884193e`](https://github.com/grokify/d2vision/commit/884193e))
- Protocol-backed panels: derive a diagram from a PIDL file, with protocol order and direction checks and warnings for unverified steps ([`884193e`](https://github.com/grokify/d2vision/commit/884193e))
- `export` package: headless Chrome capture of an SVG as PNG or animation frames, with an option to launch Chrome with `--no-sandbox` ([`4254cda`](https://github.com/grokify/d2vision/commit/4254cda))
- `export.EncodeGIF`: shared-palette, no-dither GIF encoder that stores only the changed region of each frame ([`4254cda`](https://github.com/grokify/d2vision/commit/4254cda))
- `export.InspectSVG`: read pixel size and loop length from an SVG, including SMIL and CSS animation durations ([`4254cda`](https://github.com/grokify/d2vision/commit/4254cda))
- `card render` command: write SVG, PNG and GIF from one card definition ([`b1d62fe`](https://github.com/grokify/d2vision/commit/b1d62fe))
- `svg2gif` command: convert any animated SVG, including D2 animated edges, to a looping GIF ([`b1d62fe`](https://github.com/grokify/d2vision/commit/b1d62fe))

### Documentation

- Command guides for `card` and `svg2gif`, with getting started, API reference, examples index, troubleshooting and README updated ([`a10049b`](https://github.com/grokify/d2vision/commit/a10049b))
- Card examples: a hand-drawn card and a card derived from a protocol file ([`06a3038`](https://github.com/grokify/d2vision/commit/06a3038))
- v0.3.0 release notes ([`8873832`](https://github.com/grokify/d2vision/commit/8873832))

### Build

- Add `github.com/chromedp/chromedp` v0.16.0 for headless Chrome capture ([`cdebe13`](https://github.com/grokify/d2vision/commit/cdebe13))
- Update dependencies ([`8e1934a`](https://github.com/grokify/d2vision/commit/8e1934a))

### Tests

- Unit tests for the card model, layout, flows, timing and PIDL sources, and a test that renders every example card ([`401b563`](https://github.com/grokify/d2vision/commit/401b563))

## [v0.2.0] - 2026-09-12

### Highlights

- Static D2 linter with a stable rule-code registry, YAML config, and --list / --explain
- New `review` command scoring layout, whitespace, legend, and hierarchy
- New `compact` command that shortens long node labels behind a legend
- Layout-engine-selectable rendering (Dagre / ELK) and a font-size floor

### Added

- `lint` package with `corner-near`, a compiler-based check for corner-pinned elements ([`a967d4d`](https://github.com/grokify/d2vision/commit/a967d4d))
- `text-overlap` lint check (opt-in, post-layout) for overlapping connection labels ([`a967d4d`](https://github.com/grokify/d2vision/commit/a967d4d))
- Lint rule registry with stable `Code` identifiers plus `lint --list` and `lint --explain <code>` ([`a967d4d`](https://github.com/grokify/d2vision/commit/a967d4d))
- `.d2vision.yaml` lint config (golangci-style): enable/disable rules, override severities, per-rule settings ([`a967d4d`](https://github.com/grokify/d2vision/commit/a967d4d))
- `review` command: diagram quality review across layout, whitespace, legend, and hierarchy, with agent specs/skills ([`7f6989b`](https://github.com/grokify/d2vision/commit/7f6989b))
- `compact` command: render with long node labels replaced by short numeric keys plus a legend mapping ([`ae5e5ca`](https://github.com/grokify/d2vision/commit/ae5e5ca))
- Register the `review` and `compact` commands ([`fa661f1`](https://github.com/grokify/d2vision/commit/fa661f1))

## [v0.1.0] - 2026-03-07

### Highlights

- Complete toolkit for D2 diagram parsing, generation, and AI-assisted creation
- TOON output format (default) uses ~40% fewer tokens than JSON - ideal for LLM consumption
- Embedded D2 rendering engine - no separate D2 CLI installation required
- Mermaid and PlantUML conversion support
